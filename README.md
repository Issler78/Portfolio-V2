## 🎯 Sobre o Projeto

Como estudante de Engenharia de Software com forte foco em arquitetura de **Backend (Java/Spring e PHP/Laravel)**, decidi construir este frontend não apenas para exibir meus projetos, mas para demonstrar que valorizo código limpo e boas práticas em toda a stack.

O design foi intencionalmente construído com uma estética *Clean* e *Dark*, fugindo de clichês visuais e animações exageradas, garantindo que o foco permaneça no que realmente importa: **os projetos e a resolução de problemas.**

## 🛠️ Stack Tecnológica

Embora seja um projeto 100% estático e focado no cliente (Client-Side), ele foi estruturado com ferramentas modernas e rigorosas:

- **React + TypeScript:** Para garantir componentização reutilizável e segurança de tipagem estrita (evitando o uso de `any`).
- **Vite:** Escolhido como bundler pela extrema velocidade de build e otimização de assets.
- **CSS / Tailwind:** Estilização desenvolvida com abordagem estrita **Mobile-First**, garantindo responsividade perfeita em qualquer dispositivo.
- **Static Forms API:** Integração serverless para o formulário de contato, operando de forma segura através de variáveis de ambiente protegidas.
